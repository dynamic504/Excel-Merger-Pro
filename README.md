## 📊 Merge Modes Explained

### **1️⃣ Merge into 1 Master Sheet**
Perfect for consolidating monthly/yearly reports.
```
File1.xlsx (100 rows) +
File2.xlsx (150 rows) +
File3.xlsx (200 rows)
        ↓
Result: 1 Sheet with 450 rows total
```

### **2️⃣ Keep as Separate Sheets**
Keep data organized by source file.
```
Result.xlsx
├─ Sheet: File1_Data
├─ Sheet: File2_Data
└─ Sheet: File3_Data
```

### **3️⃣ Master + Separate Sheets (All-in-One)**
Best of both worlds! Get a master sheet AND keep originals.
```
Result.xlsx
├─ Sheet: Master (all data combined)
├─ Sheet: File1_Data (original)
├─ Sheet: File2_Data (original)
└─ Sheet: File3_Data (original)
```

### **4️⃣ Group by Matching Sheet Name**
Automatically merge sheets with the same name across files.
```
Result.xlsx
├─ Sheet: Sales (merged from all files)
├─ Sheet: Expenses (merged from all files)
└─ Sheet: Revenue (merged from all files)
```

## ❓ Frequently Asked Questions (FAQ)

<details>
<summary><b>Q: Will my data be uploaded to the cloud?</b></summary>
<br>
<b>A:</b> Absolutely NOT! Excel Merger Pro is 100% offline. All processing happens on your computer. Your data never leaves your PC. We don't have any cloud infrastructure.
</details>

<details>
<summary><b>Q: Do I need to install Python, Node.js, or other software?</b></summary>
<br>
<b>A:</b> No! The app runs as a standalone HTA (HTML Application) on Windows. Just download and run. Only requirement is Microsoft Excel.
</details>

<details>
<summary><b>Q: Can it handle large files with millions of rows?</b></summary>
<br>
<b>A:</b> Yes! We've optimized it to handle massive files without freezing. However, very large files may take a few seconds to process.
</details>

<details>
<summary><b>Q: What file formats are supported?</b></summary>
<br>
<b>A:</b> We support:
- ✅ .xlsx (Excel 2007+)
- ✅ .xls (Excel 97-2003)
- ✅ .xlsm (Macro-enabled)
- ✅ .csv (Comma-separated)
- ✅ Password-protected files
</details>

<details>
<summary><b>Q: Does it work with password-protected Excel files?</b></summary>
<br>
<b>A:</b> Yes! The app can read password-protected files. However, you'll need to enter the password when opening the file.
</details>

<details>
<summary><b>Q: Is Excel Merger Pro safe? Will antivirus flag it?</b></summary>
<br>
<b>A:</b> Yes, it's 100% safe! Some antivirus software (Windows Defender, Kaspersky) may show a warning because the app uses ActiveX to communicate with Excel. This is normal for HTA applications and NOT a security threat. The source code is open-source and you can inspect it if you want.
</details>

<details>
<summary><b>Q: Can I use it on Mac or Linux?</b></summary>
<br>
<b>A:</b> Unfortunately, not yet. Excel Merger Pro is designed for Windows only (uses HTA and ActiveX). Mac/Linux support is on our roadmap for future versions.
</details>

<details>
<summary><b>Q: How much does it cost?</b></summary>
<br>
<b>A:</b> It's completely FREE! No hidden fees, no subscription, no premium version. Just download and use forever!
</details>

## 💡 Pro Tips for Best Results

Before merging, please ensure your Excel files are **clean**:

✅ **DO:**
- Remove unnecessary blank rows/columns at the end
- Ensure consistent column headers across files
- Check for merged cells that might cause issues
- Use clear, descriptive file names

❌ **DON'T:**
- Leave thousands of blank rows at the bottom
- Mix completely different data structures
- Use Excel files as poorly formatted data dumps
- Forget to make backups before merging
